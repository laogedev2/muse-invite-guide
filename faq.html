Muse Invite Code — Frequently Asked Questions

Short answers about the invite code BMIFSK, where to redeem it, and how the reward works. For the walkthrough, see the step-by-step tutorial.

What is the Muse invite code?

BMIFSK is an invite code for Muse, Meta's personal AI agent. A new user who joins Muse and redeems this code in Settings is rewarded together with the inviter: once the redemption confirms, both sides receive 1 billion Muse tokens. Exact reward terms are as stated on the official invite page at muse.ai/join.

Where do I redeem the Muse invite code BMIFSK?

On the web: Settings → General → Usage → Redeem invite code. In the mobile app: Settings → Redeem token. Enter BMIFSK and confirm.

How long do I have to redeem the code after joining?

Only the first 48 hours after you join. The redemption entry disappears after that window — redeem first, explore afterwards.

What do I get for redeeming code BMIFSK?

Both you and the person who invited you receive 1 billion Muse tokens once the redemption is confirmed. Reward amounts, validity and eligibility follow the official invite page.

How do I join Muse?

Go to muse.ai/join and complete the sign-up on web, iOS or Android. Then immediately open Settings and redeem BMIFSK, because the entry is only open for 48 hours after joining.

Which countries is Muse available in?

Muse is currently available in the United States and Canada. Availability is decided by the official page — check muse.ai/join for the latest information for your region.

What is Muse, in one paragraph?

Muse is Meta's personal AI agent. It has its own computer, browser and filesystem, can connect to your email, calendar and accounts, keeps long-term memory of your preferences, runs scheduled jobs in the background, and completes real tasks — inbox triage, research with sources, scripts that actually run, trip planning, flight tracking — before reporting back. I can't find the "Redeem invite code" entry. What happened?

Most likely more than 48 hours have passed since you joined — the entry only exists during that window. Also make sure you're signed in to the same account you just created, and that you're looking in the right place: web is Settings → General → Usage → Redeem invite code; the app is Settings → Redeem token.

The code was rejected. What should I check?

Re-type the code carefully: BMIFSK, all capitals, no leading or trailing spaces. If it still fails, verify you're inside the 48-hour window and signed in to the correct account.

Is this site affiliated with Meta or Muse?

No — this is an unofficial community guide. The official source for the invite program, rewards and availability is the invite page at muse.ai/join.
